# TimeTree 連携ワークスペース 規約 (AGENTS.md)

このワークスペースは、**TimeTree（公開カレンダー・イベント情報）のAPI調査・データ取得・カレンダー同期・外部通知等の自動化基盤**を整備するための協業領域です。

---

## 📁 ディレクトリ構成と役割

```
timetree/
├── AGENTS.md             # 本規約ファイル（スコープ・開発ルール）
├── discussion.md         # 議論の方向性、要件定義、進捗管理、アクションアイテム
├── note/                 # 調査・検証・技術メモ（01_xxx.md 形式で蓄積）
│   └── 01_public_calendar_api_research.md  # 公開カレンダー内部APIの仕様・ヘッダー・制約まとめ
├── adr/                  # 確定した方針・アーキテクチャ選定 (0001-xxx.md)
└── scripts/              # イベント取得・変換・通知スクリプト
    └── fetch_events.py   # 公開カレンダーからイベント一覧を取得するCLIツール
```

---

## 📋 運用ルール & 技術的留意点

1. **アクセス制限とレートリミットへの配慮**
   - 内部APIを利用するため、短時間に連続した大量リクエストは避け、適切なインターバル（数秒〜数分のキャッシュ等）を設けます。
2. **必須リクエストヘッダーの維持**
   - TimeTree の内部 API 通信には `X-CSRF-Token`、`X-TimeTreeA: web/2.1.0/1.0.0`、および `_session_id` Cookie が必須です。詳細は `note/01_public_calendar_api_research.md` を参照してください。
3. **知見の蓄積 (`note/`) & スクリプト化 (`scripts/`)**
   - 新しいエンドポイントやデータ構造が判明した場合は `note/` にドキュメント化し、再利用可能なコードは `scripts/` に配置します。
4. **外部連携の設計方針 (`adr/`)**
   - Google Calendar 連携、iCal 出力、Discord/LINE への通知設計などの方針決定は `adr/` に記録します。
