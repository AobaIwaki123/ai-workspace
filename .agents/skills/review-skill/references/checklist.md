# Comprehensive Skill Review Checklist

本ドキュメントは、Antigravity スキルをレビュー・監査する際の詳細チェック基準です。

## 1. ディレクトリ構造・ファイル配置
- [ ] スキルディレクトリ名が kebab-case（例: `my-awesome-skill`）である
- [ ] ルート直下に `SKILL.md` が存在する
- [ ] スクリプト類が `scripts/` に格納されている
- [ ] ドキュメント・リファレンスが `references/` に格納されている
- [ ] サンプル・設定例が `examples/` に格納されている

## 2. SKILL.md Frontmatter 検証
- [ ] ファイル先頭が `---` で始まり `---` で終わる有効な YAML Frontmatter である
- [ ] `name` フィールドが存在し、ディレクトリ名と一致している
- [ ] `name` が英小文字・数字・ハイフンのみで構成されている
- [ ] `description` フィールドが存在し、空でない
- [ ] `description` に発動条件（トリガーキーワード、利用シナリオ）が含まれている
- [ ] `description` が3人称で記述されている

## 3. Progressive Disclosure（トークン効率）
- [ ] `SKILL.md` の行数が肥大化していない（目安: 200行以下）
- [ ] 重い表や網羅的なリストが `references/*.md` に逃がされている
- [ ] `references/` への相対リンクが正しく機能している

## 4. スクリプトの品質・安全性
- [ ] 全てのスクリプト（`.sh`）に `chmod +x` が付与されている
- [ ] スクリプト先頭に適切な shebang（例: `#!/usr/bin/env bash`）がある
- [ ] `set -euo pipefail` など適切なエラーハンドリングがされている
- [ ] ヘルプ表示（`-h`, `--help`）や引数バリデーションが実装されている
- [ ] 破壊的なコマンド（`rm -rf /` 等）が含まれていない

## 5. ワークフロー・検証ステップ
- [ ] エージェントが実行すべきステップが番号付きで明確に記述されている
- [ ] 処理後の成功判定（テスト、構文チェック、出力確認）が定義されている
