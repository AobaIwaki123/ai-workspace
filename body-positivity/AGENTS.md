# ボディポジティブ運動の悪用と変質に関する調査 規約 (AGENTS.md)

このワークスペースは、ボディポジティブ運動（Body Positivity Movement）の歴史的背景、商業化・悪用による問題点、医療・健康観との対立、および派生した「ボディ・ニュートラル」等の新たな潮流に関する調査・分析をまとめる協業領域です。

---

## ディレクトリ構成と役割

```
body-positivity/
├── AGENTS.md             # 本規約ファイル（スコープ・調査方針）
├── discussion.md         # 調査目的、論点整理、進捗管理
├── note/                 # 調査・分析ドキュメント（01_xxx.md 形式で蓄積）
├── adr/                  # 確定した方針・意思決定
└── scripts/              # 関連データ収集・分析スクリプト等（必要に応じて）
```

---

## 運用ルール

1. **進捗・議論の記録 (`discussion.md`)**
   - 調査論点、背景、知見のサマリを常に整理します。
2. **知見の蓄積 (`note/`)**
   - 調査結果や多角的な視点（歴史、商業、医療、SNS文化）を `note/` 配下に連番付きマークダウンで記録します。
3. **客観性と多角的な視点の維持**
   - 感情的な批判や一方的な断定を避け、社会運動の文脈、市場構造、医学的知見を総合的に踏まえた構造的分析を行います。
4. **表記規約**
   - ドキュメント内での絵文字の使用は原則禁止とし、クリーンでプロフェッショナルな記述を維持します。
