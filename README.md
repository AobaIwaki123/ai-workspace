# ai-workspace

AIと協業するためのワークスペース集

## Workspaces

### [copilot-ci/](copilot-ci/)
GitHub CopilotをCI/CDパイプラインから呼び出す仕組みの検証・実装

- **ワークフロー**: `.github/workflows/copilot-*.yml`
- **スクリプト**: `scripts/copilot-ci.sh`
- **規約**: `copilot-ci/AGENTS.md`
- **ドキュメント**: `copilot-ci/README.md`

## 使い方

各workspace配下の `AGENTS.md` と `README.md` を参照してください。
