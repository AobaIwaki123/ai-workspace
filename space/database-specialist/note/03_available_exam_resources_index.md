# データベーススペシャリスト試験 利用可能リソース・過去問インデックス

## 概要

本ドキュメントは、トークン消費を最小限に抑えつつ、必要なタイミングでピンポイントに必要な問題・解答・採点基準を参照できるよう、IPA公式および信頼できる過去問WebリソースへのアクセスリンクとURL命名規則を一覧化したインデックスです。

### 1.2 IPA公式ファイルのURL命名規則

IPAの過去問PDFは、以下の規則的なファイル名体系に従っています。必要な問題のみをピンポイントで取得・参照する際に利用します。

- **URL形式**: `https://www.ipa.go.jp/shiken/mondai-kaiotu/<年度接頭辞>_db_<試験区分>_<種別>.pdf`
- **年度接頭辞**:
  - 令和6年: `2024r06a`
  - 令和5年: `2023r05a`
  - 令和4年: `2022r04a`
  - 令和3年: `2021r03a`
  - 令和2年: `2020r02o`（※秋期延期10月実施のため `o`）
  - 平成31年/令和元年: `2019h31a`
- **試験区分**:
  - 午前II: `am2`
  - 午後I: `pm1`
  - 午後II: `pm2`
- **種別**:
  - 問題冊子: `qs`
  - 解答例: `ans`
  - 採点講評: `cmnt`
