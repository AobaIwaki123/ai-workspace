# データベーススペシャリスト得点推論モデルと実力モニタリング仕様

## 概要

本ドキュメントは、データベーススペシャリスト試験（午前IIおよび午後試験）において、ユーザーの過去の回答・演習履歴から現在の実力を統計的に推論し、100点満点換算の「予想得点（Predicted Score）」および「合格判定」を算出・モニタリングするためのモデル仕様です。

---

## 1. 午前II 予想得点推論モデル (Multiple-Choice Prediction)

### 1.1 推定に必要な回答数と信頼度レベル

午前IIは25問中15問正解（60点以上）で合格となります。本モデルでは回答数に応じて推論の信頼度を3段階で評価します。

| 累計回答数 | 信頼度レベル (Confidence) | 推定の性質と扱い |
| :--- | :--- | :--- |
| **1〜9問** | **低 (Low / 参考値)** | サンプル不足。初期傾向の可視化のみ（参考値）。 |
| **10〜19問** | **中 (Medium / 暫定推論)** | 主要分野の傾向が把握可能。直近の弱点分野が明瞭化。 |
| **20問以上** | **高 (High / 高精度推論)** | 統計的バラツキが収束し、本番想定の確度の高い予想得点を算出。 |

### 1.2 推定アルゴリズム（直近加重 ＋ 分野別加重平均）

単純な全期間正解率ではなく、「学習による実力の向上（直近重視）」および「本番の出題比率」を反映した加重平均を採用します。

1. **直近重視の減衰係数（Recency Weight）**:
   - 直近の回答ほど重みを大きく設定（直近15問の回答に高い重み $w_i$ を付与）。
   - 過去の古い失敗に過度に引きずられず、最近の理解度を反映。
2. **分野別加重（Category Weight）**:
   - 本番の出題傾向に基づき、各分野の正解率に重みを掛け合わせて100点満点に正規化。
   - 出題比率目安:
     - 正規化理論: 28% (7問相当)
     - トランザクション・同時実行制御: 24% (6問相当)
     - 関係モデル・関係代数: 16% (4問相当)
     - 障害回復: 12% (3問相当)
     - 物理設計・インデックス: 12% (3問相当)
     - SQL・整合性制約: 8% (2問相当)

$$\text{予想得点} = \sum_{k} \left( \text{分野 } k \text{ の直近正解率} \times \text{分野 } k \text{ の出題比率} \right) \times 100$$

### 1.3 更新頻度
- **1問回答ごと**に即時再計算して履歴データとともに更新。

## 2. 午後試験 予想得点推論モデル (Descriptive Problem Prediction)

午後試験（午後I: 90分 2問選択 / 午後II: 120分 1問選択）は、大問単位のケーススタディとして採点されます。

### 2.1 推定に必要な大問数

- **午後I**: 大問3〜4問（約2年度分）
  - 概念設計系（問1系）2問 ＋ SQL/物理設計系（問2/3系）1〜2問
- **午後II**: 大問2問（概念系1問、物理系1問）

### 2.2 採点講評連動の減点採点法

午後問題の各大問（配点50点）は、以下の3要素で自己採点・AI評価を行い、得点を推論します。

| 評価要素 | 配点目安 | 主な減点要因（採点講評準拠） |
| :--- | :--- | :--- |
| **ER図・多重度 (Cardinality)** | 15〜20点 | 1対多の向きの逆転、依存/非依存の実線・破線の誤り、NULL許容の見落とし |
| **関係スキーマ (Keys & Schemas)** | 15〜20点 | 主キー漏れ、複合主キーの属性過不足、外部キーの配置誤り、履歴属性の欠落 |
| **記述設問 (Explanation)** | 10〜15点 | 採点講評で指定された業務キーワード（「改定前単価」「相殺処理」等）の欠落 |

### 2.3 更新頻度
- **大問1問を解き終えるごと**に、直近2回分の大問スコアから最新の「午後I予想得点（100点換算）」を更新。

## 3. 合格判定基準（Pass / Fail Thresholds）

算出された予想得点に基づき、実力を以下の4段階で判定します。

| 予想得点 | ステータス判定 | アクション指針 |
| :--- | :--- | :--- |
| **80点以上** | **合格安全圏 (Safe Pass)** | 実力十分。スピード向上とケアレスミス防止の演習に移行。 |
| **65〜79点** | **合格圏 (Passing)** | 合格ライン到達。直近で間違えた弱点分野のみピンポイント復習。 |
| **55〜64点** | **合格ボーダー (Borderline)** | あと一歩。配点の高い正規化理論やトランザクションの穴を重点補強。 |
| **54点以下** | **要基礎強化 (Needs Review)** | 基礎理論の再確認が必要。チェックリストと午前II過去問を集中的に周回。 |
