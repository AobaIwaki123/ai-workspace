# 過去問アセット管理・記憶ストレージ (Past Exams Asset Store)

## 概要

本ディレクトリは、IPAデータベーススペシャリスト試験の各過去問について、**「問題文」「公式解答・採点講評」「ユーザーの周回別回答・壁打ち履歴」**を永続的なアセットとしてローカルに蓄積・記憶するためのデータストアです。

セッションが終了・中断しても、このディレクトリ配下のファイルを読み込むことで、AIは過去の回答状況や躓いた思考プロセスを完全に復元して継続指導できます。

---

## ディレクトリ構造

```text
assets/past-exams/
├── README.md                      # 本仕様書
├── pdf/                           # （任意）ダウンロードした公式PDF原本の保管庫
└── <年度コード>/                  # 例: 2024-r06, 2023-r05
    └── <試験区分-大問番号>/       # 例: pm1-q1, pm1-q2, pm2-q1
        ├── question.md            # 問題文・業務要件定義・スキーマ図
        ├── official_answer.md     # IPA公式解答例 ＆ 公式採点講評（出題意図）
        └── coaching_history.jsonl # 周回別のユーザー答案・自己採点・壁打ちログ
```

---

## 各ファイルの役割

1. **`question.md` (問題文アセット)**:
   - 業務要件定義、前提条件、関係スキーマ、ER図の穴埋め対象などをMarkdown形式で保管。
2. **`official_answer.md` (公式解答・採点講評アセット)**:
   - IPA公式解答例と、採点講評（受験者の誤答傾向や出題者が求めたポイント）を固定。
   - AIはこれを絶対基準として参照し、独自の誤解やハルシネーションを防止。
3. **`coaching_history.jsonl` (周回別回答・記憶ログ)**:
   - 1行に1回の演習履歴を記録。
   - フィールド例:
     ```json
     {
       "attempt_number": 1,
       "timestamp": "2026-10-03T15:00:00+09:00",
       "time_spent_minutes": 42,
       "score_estimated": 75,
       "user_answers": {"設問1": "...", "設問2": "..."},
       "mistakes_and_misconceptions": ["注文明細の単価保持を見落とし", "外部キーのNULL許容を不指定"],
       "ai_coaching_summary": "業務ルール3の『改定前の単価を保持する』という記述の読み落としが原因。"
     }
     ```

## アセット初期化スクリプト

手元のスクリプトで指定年度のアセットディレクトリを自動Scaffoldできます。

```bash
# 例: 令和5年 午後I 問1 のアセット領域を作成
python3 .agents/skills/db-exam-coach/scripts/inspect-exam.py -y r05 -p 1 -q 1 --create-asset
```
