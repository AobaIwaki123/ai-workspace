# 読書記録・読みたい本リスト 規約 (AGENTS.md)

このワークスペースは、**読書記録・読みたい本リスト** に関する選定・感想・考察・習慣化を推進するための協業領域です。

---

## ディレクトリ構成と役割

```
space/reading/
├── AGENTS.md             # 本規約ファイル（スコープ・運用ルール）
├── discussion.md         # 読書ステータス、目的、ロードマップ、直近のアクション
├── note/                 # 読書候補リスト、作品マトリクス、読書ノート・感想メモ（01_xxx.md 形式）
├── adr/                  # 確定した読書・インプット方針 (0001-xxx.md)
└── scripts/              # 書籍情報取得等の自動化スクリプト
```

---

## 運用ルール

1. **進捗・読書ステータスの記録 (`discussion.md`)**
   - 現在読んでいる本、読了した本、次に読みたい本を管理します。
2. **候補作・感想の蓄積 (`note/`)**
   - テーマ別の推薦本リストや、作品ごとの感想・考察ノートを `note/` 配下に連番で作成します。
3. **ネタバレ防止（重要）**
   - 読書中の作品について対話やメモ作成を行う際、ユーザーから明示的な指示がない限り、未読部分のネタバレやオチの先回りを厳禁とします。
4. **出典・公式情報の記載**
   - 書籍を紹介・リスト化する際は、出版社公式ページ等の確かな情報源へのリンクを記載します。
