# ゲーム開発 × ツヨカワ 規約 (AGENTS.md)

このワークスペースは、**ゲーム開発 × ツヨカワ** に関する調査・設計・検証・自動化を推進するための協業領域です。

---

## ディレクトリ構成と役割

```
space/tsuyokawa-game/
├── AGENTS.md             # 本規約ファイル（スコープ・開発ルール）
├── discussion.md         # 議論の方向性、要件定義、進捗管理、アクションアイテム
├── note/                 # 調査・検証・技術メモ（01_xxx.md 形式で蓄積）
├── adr/                  # 確定した方針・アーキテクチャ選定 (0001-xxx.md)
└── scripts/              # 本テーマ専用のスクリプト・ツール・自動化コード
```

---

## 運用ルール

1. **進捗・議論の記録 (`discussion.md`)**
   - 議論の前提、目的、課題、ネクストアクションを常に最新に保ちます。
2. **知見の蓄積 (`note/`)**
   - 調査した仕様や技術検証の結果は `note/` に連番付きマークダウンで記録します。
3. **意思決定の記録 (`adr/`)**
   - 設計方針やアーキテクチャの選定理由は `adr/` に記録します。
4. **再現性の確保 (`scripts/`)**
   - 検証用スクリプトや実行手順は `scripts/` 配下にコード化して残します。

---

## このテーマ固有の方針

- 初期目標は、グループ固有の公式素材に依存しない「ツヨカワをゲームルールで体験できる試作」です。ゲームジャンルは固定しません。
- 公式楽曲、写真、ロゴ、肖像、声を使う場合は、公開前に権利者の許諾を確認します。許諾前の試作ではオリジナル音源・抽象モチーフ・仮素材を使います。
- ライブ予定、SNSフィード、ユーザー投稿、ランキング、継続的なコンテンツ更新をMVPの前提にしません。
- 「強くて可愛い」は、色やイラストだけでなく、成長、変換、守る、立て直すなどのゲームルールにも反映します。
- ジャンルを決める前に、ゲーム単体の面白さ、短時間の反復性、初期素材の量、権利依存度、ファンへの価値を比較します。
- 外部データを追加する場合も、データ取得失敗時にゲーム本体が遊べるローカルフォールバックを用意します。
