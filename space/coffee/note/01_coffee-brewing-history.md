# コーヒー抽出技術の歴史的変遷：サイフォンの誕生とハンドドリップの分化

## 概要

本ドキュメントでは、コーヒー抽出の歴史において「濁りのないクリアな液体をいかに安定して再現するか」という技術課題がどのように解決されてきたかを整理します。特に19世紀に蒸気圧と真空技術を応用して誕生した「サイフォン（バキューム式）」の成立背景と、20世紀初頭にペーパードリップが考案されたことで確立された「ハンドドリップ（透過法）」との技術的・構造的差異と分化の経緯をまとめます。

---

## 1. 抽出技術の歴史的タイムライン

コーヒーの抽出技術は、「煮沸式」から「重力濾過」、そして「蒸気圧・真空（減圧）の応用」、さらに「使い捨てペーパーフィルターによる透過制御」へと進化しました。

| 年代 | 出来事・器具 | 抽出方式 | 特徴と技術的課題 |
| :--- | :--- | :--- | :--- |
| **〜16世紀** | トルココーヒー（イブリック / ジェズヴェ） | 煮沸式 (Boiling) | 水と極細挽きの粉を直接火にかけて煮出す最古のスタイル。微粉が液中に浮遊し、濁りと過抽出による強い苦味が残る。 |
| **18世紀初頭〜** | 布（ネル）による重力濾過 | 透過・浸漬併用 | フランス等で麻や木綿の袋に湯を通す試みが始まる。微粉の流出は抑えられたが、目詰まりが早く抽出速度の制御が困難であった。 |
| **1800年頃** | ドゥ・ベロワのポット (Cafetière Dubelloy) | 重力透過 (Drip) | 穴あき陶器・金属プレートを用いた二重構造ポット。現代のドリップの原型だが、お湯の落ちる速度が遅く、抽出中に湯温が急激に低下する問題があった。 |
| **1830年代** | ロイフ (Loeff) による原型考案 | 減圧浸漬 (Vacuum) | ドイツ・ベルリンのロイフが気圧差を利用した抽出器具の原型を考案。 |
| **1841年** | ヴァシュー夫人 (Madame Vassieux) による特許取得 | 減圧浸漬 (Vacuum / Siphon) | フランスのヴァシュー夫人が実用的なガラス製2連球型バキュームコーヒーメーカーの特許を取得。サイフォン式の商業的普及の起点となる。 |
| **1908年** | メリタ・ベンツ (Melitta Bentz) によるペーパードリップ発明 | ペーパー透過 (Paper Drip) | ドイツ・ドレスデンにて、真鍮製カップと吸取紙を用いたろ過装置を考案。使い捨てフィルターによる衛生性とクリーンカップを実現。 |
| **1920年代〜** | 日本でのサイフォン導入と普及 | 減圧浸漬 | 珈琲サイフォン社（現・コーノ）の河野彬氏らによって日本に紹介・改良され、喫茶店文化の象徴として定着。 |
| **1950年代〜** | ドリッパーの形状とリブ（溝）の構造分化 | 透過 (Drip) | カリタ（3つ穴台形）、メリタ（1つ穴台形）、コーノ（円錐形・リブ短め）、ハリオ（V60・スパイラルリブ）など、湯抜け速度を設計した器具が多様化。 |

## 2. サイフォン（バキューム式）誕生の背景

### 2.1 産業革命期の科学技術と課題解決
19世紀前半、ヨーロッパでは産業革命に伴いガラス製造技術が向上し、熱力学や蒸気機関への関心が高まっていました。当時普及していた布や陶器によるドリップポットには以下の大きな欠点がありました。

1. **目詰まりと抽出時間の長期化**: 粉が細かすぎると湯が落ちず、粗すぎると薄くなる。
2. **抽出中の温度低下**: 重力だけに頼って滴下させている間に外気で湯が冷め、十分な風味成分が抽出できない。
3. **雑味と粉っぽさ**: 粗いろ過材では微粉が通り抜け、布の手入れが不十分だと酸化臭が移る。

### 2.2 蒸気圧と減圧ろ過の応用
これらの課題を一挙に解決したのが、蒸気圧と真空（減圧）を利用するバキューム式器具でした。

- **上昇工程（蒸気圧）**:
  下部フラスコ内の水を加熱すると水蒸気が発生し、逃げ場を失った水蒸気の膨張圧力によって、湯が中央の管（ロート）を通って上部ボールへと押し上げられます。
- **抽出工程（高温浸漬）**:
  上部ボール内で湯とコーヒー粉が一定温度で接触し、浸漬（Immersion）状態を維持します。抽出者はヘラ等で攪拌し、短時間で均一な成分抽出を行います。
- **下降工程（減圧吸入）**:
  熱源を外すと、下部フラスコ内の空冷が進み、水蒸気が水に戻ることで内部の圧力が急激に低下（準真空状態）します。大気圧との圧力差によって、上部の液体がフィルター（布や紙）を通じて一気に下部へと吸い込まれます。

1841年にフランスのヴァシュー夫人（Madame Vassieux）が取得した特許は、上下のガラス球体を装飾的な金属フレームにセットしたものであり、サロン文化における視覚的なエンターテインメント性とクリーンな味わいの両立によって上流階級の間で大きな人気を博しました。

## 3. ハンドドリップの革新と分化

### 3.1 メリタ・ベンツによるペーパードリップの発明
サイフォンは透明で美しい液体が得られる反面、薄いガラス球の破損リスク、アルコールランプや器具の準備・洗浄の煩雑さといったメンテナンス上の課題を抱えていました。また布フィルターの煮沸保管も不可欠でした。

1908年、ドイツの主婦メリタ・ベンツ（Melitta Bentz）は、息子の学用品であった吸取紙（Blotting paper）を真鍮製カップの底に敷き、小さな穴を開けた器具で抽出するアイデアを考案しました。
同年、ドイツ帝国特許庁（Kaiserliches Patentamt）に実用新案として登録され、世界初のペーパードリップシステムが誕生しました。

- **利点**:
  - 使い捨てフィルターにより、布の管理に伴う酸化油分や雑菌の混入を完全に排除。
  - 器具がシンプルで割れにくく、家庭でも安全・迅速に抽出可能。
  - コーヒーオイル（脂質）と微粉がペーパーに吸着され、極めてすっきりとしたクリアカップを実現。

### 3.2 抽出メカニズムの違いによる技術的分化

ペーパードリップの普及とドリッパー構造の改良が進むにつれ、サイフォンとハンドドリップは抽出原理の面から明確に区別されるようになりました。

| 比較項目 | サイフォン (Siphon / Vacuum) | ハンドドリップ (Pour Over / Drip) |
| :--- | :--- | :--- |
| **主たる抽出方式** | **浸漬法 (Immersion)** ＋ 減圧ろ過 | **透過法 (Percolation)** ＋ 重力ろ過 |
| **お湯と粉の接触** | 上部ロート内で全量の湯に粉が一定時間浸かる | 新しい湯が粉層を通過しながら成分を溶かし出す |
| **温度管理** | 加熱し続けるため90℃以上の高温抽出を維持しやすい | 注湯やドリッパーからの放熱により徐々に温度が推移する |
| **味の再現性** | 攪拌時間と火加減が一定であればブレが少ない | 注湯速度・注ぐ位置・湯量・注ぎ分け回数に大きく左右される |
| **風味特性** | 高温による強いアロマ立ち、クリーンでまろやかなボディ | 酸味から苦味・甘味への成分グラデーション、繊細なフレーバー |
| **主なフィルター素材** | ネル（布）、ペーパー、金属メッシュ | ペーパー（晒 / 未晒）、ネル、ステンレスメッシュ |

## 4. 現代における役割と文化的棲み分け

1. **サイフォン**:
   - 日本の喫茶店文化（大正から昭和）において、カウンター越しに見せる職人技と演出美として発展。
   - 抽出温度が高く保たれるため、深煎り豆の香ばしさや力強い香りを引き出す器具として愛用され続けている。
2. **ハンドドリップ**:
   - 2000年代以降のサードウェーブ・スペシャルティコーヒー運動において、単一農園（シングルオリジン）のテロワールや繊細な果実味を表現するための標準器具として定着。
   - ハリオV60などの円錐型ドリッパーは、注ぎ手の技術（流速制御）によって抽出プロファイルを自在に調整できるツールとして、世界的な競技会（World Brewers Cup等）の中心となっている。
