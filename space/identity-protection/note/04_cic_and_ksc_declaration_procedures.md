# 04. CICおよびKSC（全銀協）インターネット本人申告の完全実行手順書

- 作成日: 2026-10-01
- テーマ: CICおよびKSC（全国銀行個人信用情報センター）におけるインターネット本人申告の具体的な操作手順およびトラブル回避策

---

## 1. 事前準備チェックシート

手続きを開始する前に、手元に必要な機材や情報を確認します。両機関とも**スマートフォン**での操作を強く推奨します。

### CIC申告用の準備物
- [ ] クレジットカード会社等に登録している自分の携帯電話
- [ ] 運転免許証番号（12桁の正確な控え）
- [ ] 決済手段（クレジットカード、PayPay、楽天ペイ、キャリア決済のいずれか）
- [ ] メモ用紙と筆記用具（電話で発行される受付番号の記録用）
- [ ] 警察への届出情報（届出日、警察署名、受理番号 ※任意だが推奨）

### KSC申告用の準備物
- [ ] NFC対応スマートフォン
- [ ] マイナンバーカード（有効期限内）
- [ ] マイナンバーカードの暗証番号（利用者証明用電子証明書の数字4桁）
- [ ] 決済手段（クレジットカード、PayPay、キャリア決済 ※手数料500円）

---

## 2. CIC（指定信用情報機関）の申告手順

**特徴**: 即日・その場で登録完了（所要時間：約10分）  
**受付時間**: **8:00 〜 21:45**（年末年始含む）  
**利用手数料**: 1,000円（税込）

### Step 1: 受付番号の電話取得
1. クレジットカード会社に届け出ている携帯電話から、CIC受付専用ダイヤルへ発信します。
   - **電話番号**: **`0570-021-717`**（ナビダイヤル・通話料有料）
2. 音声ガイダンスに従って操作し、発行される**6桁の受付番号**をメモします。
   - クレジットカード決済を利用する場合は、この電話操作中にカードの有効期限の入力が求められます。
   - ※取得した受付番号は**1時間のみ有効**です。直ちにStep 2へ進んでください。

### Step 2: CIC申告専用サイトへアクセス
1. スマートフォンのブラウザ（iPhoneはSafari、AndroidはChrome）でCICの「インターネットで本人申告する」ページを開きます。
2. 利用規約と注意事項を確認し、「同意する」にチェックを入れます。
3. **「本人申告登録（紛失盗難）を行う」**ボタンを選択します。

### Step 3: 電話番号認証とSMS認証
1. Step 1で取得した「受付番号（6桁）」を入力します。
2. 受付番号取得に使用した「電話番号」を入力します。
3. 「インターネット本人申告登録の申込を行う」をタップします。
4. PayPay、楽天ペイ、キャリア決済を選択した場合は、スマートフォン宛てにSMSで届く**認証コード**を入力します。

### Step 4: 申告情報および免許証情報の入力
1. 氏名（カナ）、生年月日等の基本情報を入力します（漢字氏名や住所はCIC登録情報から自動引用されます）。
2. 本人確認書類の種別で**「運転免許証」**を選択します。
3. **運転免許証番号（12桁）**を慎重に入力します（誤入力があると金融機関の照合で警告が出ないため、複数回確認してください）。
4. 紛失・盗難・流出の発生日を入力します。
5. 警察届出情報（届出警察署、届出日、受理番号）を入力します。

### Step 5: 手数料（1,000円）の決済
1. 選択した決済方法（クレジットカード、PayPay、楽天ペイ、キャリア決済）の決済画面へ進み、1,000円の支払いを完了します。
2. ※画面内の「確定」ボタンを押した瞬間に手数料が発生します。

### Step 6: 完了確認
1. 画面上に「本人申告情報登録受付完了」が表示されたことを確認します。
2. 登録メールアドレス宛に `i-shinkoku@cic.co.jp` から受付完了メールが届きます。
   - ※CICの正規メールにファイル添付やURLリンクは一切ありません。フィッシング詐欺に注意してください。

## 3. KSC（全国銀行個人信用情報センター）の申告手順

**特徴**: 本人確認審査に1〜3営業日を要する（即日完了ではない）  
**受付時間**: 24時間受付（審査および結果通知は全銀協の営業日対応）  
**利用手数料**: 500円（税込）

### Step 1: 申告受付ページへアクセス
1. スマートフォンのブラウザで全銀協（KSC）サイトの**「本人申告の手続き インターネットによる申告手続」**ページを開きます。
   - ※「本人開示」と画面が似ていますが、必ず「本人申告」であることを確認してください。
2. ページ最下部にある**「上記の事項を承諾のうえ、申告内容の登録を申し込む」**ボタンをタップします。

### Step 2: メールアドレスの登録
1. 連絡用メールアドレスを入力して送信します。
2. 届いた確認メール（送信元: `@zenginkyo.or.jp`）内のリンクをタップして申込画面へ進みます。

### Step 3: 申告情報の入力
1. 氏名、生年月日、性別、住所、電話番号、勤務先名等を入力します（旧姓・旧住所での登録は不可）。
2. 紛失・盗難・漏えいにあった書類として**「運転免許証」**を選択します。
3. 発生年月日（流出が判明した日など）を入力します。
   - ※申告コメントは定型文（「私は、○年○月○日に運転免許証を紛失または盗難にあいました。」）として登録されます。

### Step 4: マイナンバーカードによる公的個人認証
1. 画面の案内に従い、専用の本人確認アプリ**「TRUSTDOCK」**をインストール・起動します。
2. マイナンバーカードの利用者証明用電子証明書の暗証番号（数字4桁）を入力します。
3. スマートフォンの背面にマイナンバーカードを密着させ、カード情報を読み取ります。
4. 読み取り完了後、ブラウザ画面に戻り申込完了画面を確認します。

### Step 5: 本人確認の審査待ち（1〜3営業日）
1. 全銀協側で本人確認の審査が行われます。
2. 通常、**1営業日〜3営業日**で「本人確認結果通知メール」が登録アドレスに届きます。

### Step 6: 手数料（500円）の決済と登録完了
1. 結果通知メールに記載された支払い用URLにアクセスします。
2. クレジットカード、PayPay、またはキャリア決済で手数料500円を支払います。
   - **注意**: キャリア決済を選択する場合は、**必ずスマートフォンのWi-FiをOFFにしてモバイルデータ通信（4G/5G）**でお支払いください（Wi-Fi接続時はエラーとなり最初からやり直しになります）。
3. 決済完了後、正式にKSCのデータベースへ本人申告情報が登録されます（登録期間：5年間）。

## 4. トラブルシューティング（よくある失敗と対策）

| 発生した問題 | 考えられる原因 | 対処方法 |
| :--- | :--- | :--- |
| **CICで受付番号が通らない** | クレジットカード会社に登録されていない電話番号から発信した。 | 現在利用しているカード会社のマイページで登録電話番号を確認し、その番号から再度発信してください。 |
| **CICで1時間を経過した** | 受付番号取得から1時間以上経過した。 | 受付番号は自動失効します。手数料は発生していないため、再度電話をかけて新しい受付番号を取得してください。 |
| **CICで現住所と違う** | カード会社側の住所変更手続きが未完了。 | Web申告は中止し、現住所の本人確認書類コピーを添えて「郵送申告」を行ってください。 |
| **KSCでカード読み取りエラー** | スマホのNFC位置のズレ、またはカバーの厚み。 | スマホケースを外し、マイナンバーカードの中央部をスマホのNFCマーク（背面上部または中央）にしっかり密着させて静止してください。 |
| **KSCでキャリア決済失敗** | Wi-Fiに接続されたまま操作した。 | Wi-FiをOFFにしてキャリア回線（モバイル通信）に切り替えた上で決済画面を開き直してください。 |
