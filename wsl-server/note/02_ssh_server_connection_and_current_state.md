## 4. 「完全にクリーンとは言えない」状態から統合手順書への昇格ポイント

試行錯誤しながら接続まで到達した場合、設定の重複や不要なパッケージ・ゴミファイルが残っていることがあります。後から清書する際のチェックポイントは以下の通りです：

1. **Windows 側の設定クリーンアップ**:
   - 不要な `netsh` ポートプロキシ設定や重複したファイアウォールルールの特定
   - `%USERPROFILE%\.wslconfig` の設定パラメータの整理
2. **WSL2 / Linux 側の設定クリーンアップ**:
   - `/etc/ssh/sshd_config` または `/etc/ssh/sshd_config.d/*.conf` の設定を最小・セキュアな構成に集約
   - `/etc/wsl.conf` の標準化
   - サービスの自動起動設定（`systemctl enable ssh`）の確認
3. **再現可能な自動化スクリプトへの落とし込み**:
   - 手動で打ち込んだコマンドを `scripts/setup-ssh.sh` や PowerShell スクリプトに抽出
