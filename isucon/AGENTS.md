# ISUCON 準備ワークスペース 規約 (AGENTS.md)

このワークスペースは、**ISUCON（Iikanji ni Speed Up Contest）初参加に向けた事前準備・学習・秘伝のタレ（スクリプト／設定テンプレート）整備・過去問演習**を体系的に進めるための協業領域です。

---

## 📁 ディレクトリ構成と役割

```
isucon/
├── AGENTS.md             # 本規約ファイル
├── discussion.md         # 議論の方向性、準備ロードマップ、進捗管理
├── note/                 # 調査・学習メモ（ボトルネックパターン、計測ツール解説等）
│   ├── 01_basics.md      # ISUCONの基本ルール・当日の流れ・心構え
│   ├── 02_profiling.md   # 計測・プロファイリング（alp, pt-query-digest, pprof等）
│   ├── 03_middleware.md  # Nginx, MySQL, Redis, OS設定の基本・勘所
│   ├── 04_app_tuning.md  # アプリケーション高速化（N+1、インデックス、インメモリキャッシュ等）
│   └── 05_checklist.md   # 当日タイムライン＆チェックリスト（開始直後・終了前）
├── adr/                  # 確定した方針・アーキテクチャ選定（採用言語、ツールセット等）
├── scripts/              # 秘伝のタレ（デプロイスクリプト、初期化スクリプト、ログ集計等）
└── templates/            # ミドルウェア設定テンプレート（nginx.conf, my.cnf, etc.）
```

---

## 📋 運用ルール

1. **進捗・議論の記録 (`discussion.md`)**
   - 準備タスクの進捗状況、ユーザーの希望（使用言語、チーム構成、目指すスコア等）を常に最新に保ちます。
   - 次にやるべきアクションアイテムを明確化します。

2. **知見の蓄積 (`note/`)**
   - 調査した内容や過去問の解説、チューニングノウハウは `note/` にトピックごとにドキュメント化します。

3. **意思決定の記録 (`adr/`)**
   - 言語選定（例: Go, TypeScript, Python等）、監視・計測スタックの選定などは `adr/` に記録します。

4. **再現性・スクリプト化 (`scripts/`, `templates/`)**
   - 当日素早くセットアップできるよう、コマンドや設定は極力スクリプト化・テンプレート化します。
   - 汎用的な自動化ツールは `.agents/skills/` への切り出しも検討します。
